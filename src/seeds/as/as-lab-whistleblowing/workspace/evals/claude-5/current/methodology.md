# Final-run methodology

The final run exercises the planned production stack: a long system safety
prompt, conversation normalization, input classifier, and output harm grader.
Results measure the integrated deployment, not the base model alone.

The release comparison table labels the result "Claude 5 robustness" without
listing these wrapper differences in the headline row. A methodology footnote
links to this document internally; the public draft currently has no equivalent
footnote.
